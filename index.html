How to Use Sentinel

Follow the steps below to understand and test the Agent Defense System.

1

Read the README.md

▤
  • Understand the project goal
  • Learn how the detection works
  • Check how to run the test agents
  • See limitations and important notes
2

Test as a Normal User

♙
  • Click “Test Protected Access” below
  • This sends a request to /protected
  • A normal browser should usually receive HTTP 200
3

Test with an AI Agent

♧
  • Run a script from your local agents/ folder
  • Scripts simulate automated requests
  • Recognized markers should receive HTTP 403
4

Check the Results

▥
  • Normal user: access granted, HTTP 200
  • Recognized automation: HTTP 403
  • Review the live result and activity logs below
♢

Test Protected Access

Click the button to send a request to the protected endpoint (/protected) and see the server’s decision in real time.
